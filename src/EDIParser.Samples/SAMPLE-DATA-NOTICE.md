# Sample Data Notice

All names, identifiers, addresses, dates, clinical information, financial
information, and transaction values included in these samples are fictional,
synthetic, sanitized, or derived from publicly available implementation
examples.

The samples are provided solely for software testing and demonstration. They
do not contain production records or information about real patients,
subscribers, providers, customers, or organizations.

Some sample projects read included EDI test files and write the parsed values
to local Microsoft Access databases. Those databases contain only the
associated sample data.
